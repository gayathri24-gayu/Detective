Description:
Goal: Develop a text-based adventure game using Python. The game will be interactive, allowing users to make choices that navigate through different scenarios. It will feature multiple paths, inventory management, and decision-based outcomes, providing a rich user experience by implementing basic Python concepts such as loops, conditionals, and functions.

Structure:
1. User Interface:
Console-Based UI:

*Design a console-based user interface for input and output.

*Allow users to interact with the game using simple text commands.

Optional GUI using Tkinter:

Create a graphical user interface (GUI) using Tkinter for a more interactive experience (optional).

2. Core Functionality:
Game Flow:

*Implement the main game loop that controls the game flow.

*Use functions to handle different game scenarios and player choices.

Multiple Paths:

*Design branching storylines that allow for multiple paths based on player decisions.

Inventory Management:

*Implement an inventory system to manage items that players can collect and use.

Decision-Based Outcomes:

Create different outcomes based on player decisions, influencing the game's progress and ending.

3. Reports (Optional):
Game Logs:

Generate logs of player choices and game events.

Save logs into a text file or a database for later reference
